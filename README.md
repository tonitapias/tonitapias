### Hi, I'm Toni 👋

I make **[MeteoAI](https://meteotoniai.com)**, a weather forecast app for anywhere in the world. It combines global models with 14 high-resolution regional models, live radar and satellite, official alerts and an AI-written summary. I started it to know what the weather would be like wherever I was heading, and it kept growing.

- 🌦️ **[meteoai](https://github.com/tonitapias/meteoai)**: the app (React + TypeScript, PWA) · [meteotoniai.com](https://meteotoniai.com)
- 🧾 **[comptes-clars](https://github.com/tonitapias/comptes-clars)**: splitting trip expenses without arguments
- 🛰️ I've contributed to **[LibreWXR](https://github.com/JoshuaKimsey/LibreWXR)**, an open-source weather radar (European OPERA data)

My code and docs are mostly in Catalan. Issues and ideas are welcome in any language.
